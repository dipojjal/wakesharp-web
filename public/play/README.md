# Play Console evidence

 is the demonstration Google Play asks for
with the FOREGROUND_SERVICE_MEDIA_PLAYBACK declaration (App content → Foreground
service permissions). It is a screen recording of the Android app: WakeSharp is
put in the background, the alarm fires on its own, and its ongoing notification
appears over the launcher while the alarm tone plays; reopening the app returns
to the ringing screen.

Not linked from the site. It exists only so the declaration has a stable public
URL that we control, rather than a third-party account. Re-record it if the ring
screen or the notification changes materially.
